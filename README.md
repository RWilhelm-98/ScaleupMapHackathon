## Challenge 2: Smarter Onboarding

How might we use what we learn about a new user to send them to the right tool automatically?

Build or design a system that:

Collects a few answers about the user
Stores them as a profile
Decides which tool they need (rules, scoring, or AI)
Sends them there and tracks whether it worked
Bonus directions (optional, but they would help):

How might we email users helpful tips based on how they answer the survey?
How might we keep users engaged after they sign up, based on those same answers?
Show us:

Your decision logic, as a flowchart, spreadsheet, or code
Two different users getting two different results
